# Website Ulang Tahun (React + Vite)

## Menjalankan
    npm install
    npm run dev        # buka alamat yang muncul (http://localhost:5173)

## Menambah foto & video
1. Taruh file di `public/media/` (video perlu gambar sampul `.jpg`)
2. Daftarkan di `src/moments.js`
3. Ubah nama, umur, dan pesan ucapan di `config` pada file yang sama

## Build untuk online
    npm run build      # hasil di folder dist/ (upload ke Netlify / Vercel / GitHub Pages)
